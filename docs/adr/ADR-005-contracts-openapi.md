# ADR-005 — قرارداد zod → OpenAPI + کلاینت تایپ‌دار

- **وضعیت**: پذیرفته‌شده
- **تاریخ**: ۱۴۰۵ آبان

## زمینه
v2 داشبورد و API را با پاسخ‌های دستی هم‌تراز نگه می‌داشت؛ هرمس ۴۵KB روتر Python/JS داشت.
تغییر شکل پاسخ در سمت سرور، خطای ران‌تایم در سمت UI می‌ساخت.

## تصمیم (فاز ۲)
قراردادها فقط یک‌بار در `packages/contracts` با zod تعریف می‌شوند؛ از همان‌ها تولید می‌شود:
1. OpenAPI 3.1 (داکیومنت زنده‌ی `/api/v1/docs`)
2. کلاینت تایپ‌دار TypeScript برای dashboard
3. اعتبارسنجی request/response خودکار در Fastify

## پیامدها
- ✅ تغییر schema = خطای کامپایل در مصرف‌کننده، نه خطای ران‌تایم کاربر.
- ✅ مستندات API همیشه با کد هم‌زمان است.
- ❌ یک وابستگی زنجیره‌ی build اضافه — پذیرفتنی.
